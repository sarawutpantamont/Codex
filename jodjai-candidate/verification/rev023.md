## Limits

No physical iOS device test or access to real user records. Browser snapshots share the same failure domain as live browser data. A separately retained file is required if browser data is removed or an unprotected client is first opened on another origin. Previous app versions do not acquire the new write lock; close them after exporting a backup. Service-worker origin protection starts after installation/control. A browser can automatically activate a waiting worker after all clients close, so the explicit update button is not claimed to gate every browser lifecycle path.
